# 安装前提与注意事项

适用版本：0.1.0-rc1（说明补充版）。本文件与 README.md 一起使用。

## 能否在中国大陆使用

**理论上可以，条件满足后本地 USB 控制可以工作。** 运行链路是 Windows → USB → iPhone 上的 WDA → 本机浏览器画面；原生点击和界面读取不需要海外云控服务器。该结论是基于已检查实现与现有设备测试的技术推断。

**尚不能保证大陆用户下载后直接成功。** 首次安装和约七天一次的免费续签有联网步骤；下载文件齐全不代表 Apple 签名、开发镜像、手机信任验证也能离线完成。需要用当地网络实际走完一次首装与一次到期续签才能确认该环境可用。

## 安装前必须具备

| 项目 | 前提 | 如何确认 |
|---|---|---|
| Windows | Windows 10/11 的 Intel/AMD x64 版本 | 本包不支持 32 位或 Windows ARM；预留至少 3 GB 可用空间 |
| 本机权限 | 可以运行套件、安装必要 Apple 驱动 | 驱动安装可能出现 UAC，由本人确认；受组织管理的电脑需遵守管理员策略 |
| 手机 | 能正常开机、解锁，且供电稳定 | 已验证 iPhone SE 2 / iOS 18.5；其他型号/版本需要单独验证，不能据此声称全部兼容 |
| 数据线和接口 | USB 数据通道正常的 Lightning/USB-C 线及接口 | 仅能充电的线不够；充电模块故障的手机必须确认能稳定传输数据，并有足够电量维持使用 |
| Apple 设备组件 | Apple Mobile Device Support 可用 | iTunes 能识别手机，Apple 设备服务正常；已有可用组件不必重装 |
| USB 配对 | 手机已经“信任此电脑” | 手机解锁后本人确认；不能通过复制别人配对文件替代 |
| Apple 账号 | 自己持有、能正常登录并接收验证的账号 | 在所选签名工具里本人完成密码/验证码；无需把账号交给助手。免费签名配额须有可用余量 |
| 开发权限 | 开发者模式、个人签名信任、XCTest 授权 | 开发者模式重启确认、VPN 与设备管理信任、XCTest 指纹/密码验证，按系统提示完成 |
| 网络 | 可完成 Apple 登录、签名、信任与开发镜像准备 | 首次准备时电脑和手机都应可正常联网；包内 Doctor -Network 只作辅助，实际完成流程才算通过 |
| 运行时 | Install 成功，配置指向自己的设备和 WDA | 依次执行 Install.ps1、Configure.ps1、Start.ps1；手机和电脑保持 USB 连接 |

USB 方案不要求手机与电脑连接同一个 Wi-Fi，也不需要 AirPlay 接收端、付费投屏工具或 Mac。它仍要求有效的 WDA 签名；预编译 IPA 本身没有替用户签好名。

签名工具可选已验证的 Sideloadly 或[爱思替代路线](AISI-SIGNING.md)。爱思仍需要自己的 Apple 账号、Apple 在线验证和约七天续签；当前仅完成指南与安装器准备，WDA 兼容性未实测。

## 使用前应了解

1. **免费需要维护。** 普通免费账号签名的应用约 7 天有效，使用同一账号和同一 IPA 覆盖续签。本套件尚未验证完整自动刷新周期，不能承诺永久免续签。[Sideloadly 官方 FAQ](https://sideloadly.io/faq.html)
2. **账号与确认由本人处理。** Sideloadly 是第三方签名工具，本机使用的安装器没有 Windows 数字签名。核对官方来源及 SHA-256 后自行决定使用；不要在聊天、GitHub 或共享文件中放账号密码、验证码、私钥和登录缓存。
3. **当前画面服务有网络暴露限制。** 电脑网页只监听 127.0.0.1，但手机端 MJPEG 广播尚未证明限制在回环接口。使用可信且具备客户端隔离的网络，或在手机设置中关闭 Wi-Fi 后通过 USB 操作；关闭 Wi-Fi 会影响无蜂窝数据手机的联网 App。不要把公共 Wi-Fi 当成安全使用场景。[安全说明](SECURITY.md)
4. **手机必须处于可操作状态。** 断线、锁屏、证书过期或 XCTest 确认超时会中断控制。此方案不会绕过设备密码、Touch ID 或系统权限。看到过期画面时停止点击，先恢复连接。
5. **开发镜像仍有下载依赖。** 当前工具默认涉及 GitHub raw 和 Apple 服务；重启或系统升级后可能需要重新挂载、更新兼容组件。不要在已稳定使用时无准备地升级 iOS 或整套依赖。
6. **识别结果需要核验。** WDA 提供原生元素树，但部分自绘 App 可能只有少量可访问元素；必要时用截图辅助。实际 App 里的登录、支付或系统认证限制不会因为安装 WDA 而消失。
7. **商店地区与 USB 控制分别处理。** 不需要为搭建这个桥先退出 iCloud 或切换 App Store。某个 App 在当前商店地区不可下载，是该 App 的安装问题，不能靠 WDA 改变其上架范围。
8. **本地桥与 AI 服务分别验收。** 手动浏览器控制不需要 AI 登录；让 AI 助手操作，还需要用户自己的助手环境在当地可用。安装此包不会自动解决第三方 AI 服务的网络或地区条件。
9. **使用包内固定文件。** 安装器、运行时与 IPA 不要换成来源不明的修改版。校验失败先停止排查，不关闭杀毒、TLS 校验或系统安全策略。已有可用 Apple/iCloud 环境不应盲目降级。
10. **妥善处理文件。** 配置、日志、UI XML、截图可能含设备或个人信息，留在本地。完整本地包包含专有前置安装器，不等于取得公开再分发许可；公开发行另按 RELEASE-CHECKLIST.md 验收。

## 最短安装顺序

解压并校验 → Install.ps1 → 检查/安装 Apple 组件 → USB 信任 → 所选工具签名并安装 WDA → 手机开发者模式及签名信任 → Configure.ps1 → Start.ps1 → 手机 XCTest 确认 → 用计算器验证点击、画面及滑动。

成功标准是电脑操作确实作用于手机、画面及时更新、重新连接能够恢复。只显示设备名称、只出现投屏窗口或网络探测成功，均不算完成安装。
