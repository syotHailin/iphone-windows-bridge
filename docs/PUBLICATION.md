# 当前公开发布范围

当前公开版本为源码与技能预览，包含新增的爱思替代签名指南。代码和指南均保留原生 WDA、网络、账号与续签条件的验证边界。

公开仓库提供：控制程序、实时网页、配置/诊断/安装辅助脚本、中文技能、来源与版本清单、验证记录、爱思替代方案。

完整本地候选包另外包含运行时、Python 依赖、go-ios、未签名 WDA 和私人下载准备的前置安装器。以下内容不包含在当前公开仓库或源码 Release 中：

- 任何个人设备配置、配对文件、证书、账号缓存、原始手机截图或日志。
- Apple、Sideloadly、爱思的专有安装器副本；公开保留官方获取方式与哈希校验入口。
- 尚未完成全部传递依赖再分发核查的离线二进制集合。

源码 Release 只用于代码审阅和技能集成，不是即装即用的完整离线包。首次部署应遵守 README 及安装前提，并自行取得所需官方组件。完整公开二进制发行条件见 RELEASE-CHECKLIST.md；不要宣传中国大陆首装或免费续签周期已经全部实测。
