# 安全边界

本地页面监听 `127.0.0.1`，验证 Host、Origin、内容类型和自定义请求头，不开放 CORS。输入坐标必须在范围内，方向不一致或画面超过 5 秒没有数据时拒绝点击。只停止本套件登记且 PID、创建时间与路径匹配的进程。这些检查不防御同一 Windows 用户下的恶意程序。

WDA 通过 `USE_IP=127.0.0.1` 限制 HTTP 控制服务；这**不能证明 MJPEG 画面端口也受此限制**。对照 [FBTCPSocket.m](https://github.com/appium/WebDriverAgent/blob/v13.2.0/WebDriverAgentLib/Routing/FBTCPSocket.m)，上游截图广播接受连接时未指定回环接口。现有预编译产物也没有可复现构建证明。因此不要将“电脑网页仅本机访问”宣传成“整个手机没有局域网暴露”。

本候选版保留已验证的画面路线，并要求可信隔离网络或手机关闭 Wi-Fi 后使用 USB。下一版公开稳定发行应从固定 WDA 源码构建，将截图监听接口显式限制为回环，再在实机从另一台局域网设备验证无法连接；仅修改 Python 网页无法修复手机端监听。

本套件不收集 Apple 账号、密码、验证码、证书私钥，也不复制手机配对记录。WDA 可控制设备，启动期间请保护电脑账号和 USB 接入。Sideloadly 是独立第三方工具，其凭据处理不是本套件可保证的部分。身份确认由使用者在手机或官方/签名工具界面亲自完成。

本地 config、日志、UI XML 和截图可能包含个人数据，不上传公共仓库。Doctor 默认只输出数量、版本和错误类型；网络探测不上传手机标识，不执行登录。WDA 源码和依赖属于不同权利人，不以本项目名义替第三方提供安全保证。
