# 爱思助手：替代签名路线（待实机验收）

爱思替代 Sideloadly 的签名步骤，不替代 Apple 验证、开发者模式、WDA/XCTest 或开发镜像。**本指南依据官方教程整理，尚未实测本 IPA 的爱思签名、XCTest 启动及七天续签。** 官方通用签名教程发布于 2020 年；当前界面和 iOS 18.5 兼容性仍需验证。现有 Sideloadly 路线保留为本机已验证的回退方案。

## 安装前提

- Windows x64，Apple 设备驱动与 USB 数据连接正常，手机解锁并信任电脑。
- 用户自己的 Apple 账号可登录、完成双重认证，且有可用签名配额；无需退出手机 iCloud 或切换 App Store 地区。
- 从[爱思官网](https://www.i4.cn/pros/pc.html)获取 Windows x64 安装器。它是第三方程序；下载校验不代表已审计其账号处理。使用包内副本前核对 private-prerequisites 清单。
- 也可运行 `powershell -NoProfile -File .\Fetch-Prerequisites.ps1 -Component i4`，下载固定的 v9.21.010 x64 文件并检查 SHA-256 与 Windows 签名；脚本不会安装或登录。文件版本来自官网链接，非从安装器版本资源提取。
- 准备 `vendor/WebDriverAgent-13.2.0-no-dsym.ipa`，不使用别人的已签名 IPA、证书或登录缓存。
- 电脑与手机可完成 Apple 在线签名和信任验证；国内软件和下载地址不代表其所有后台服务在每条大陆网络均可达。

## 操作顺序

1. 如果控制器已运行，先 Stop。保留旧 IPA、原工具和本地配置；不要先删除已经能工作的 WDA。
2. 安装并打开爱思，连接目标手机。仅使用此次签名所需功能，不选择刷机、抹除或恢复。
3. 按实际界面进入“工具箱 → IPA 签名/IPA 文件签名”，添加上述 IPA。
4. 选择个人 Apple ID 签名，核对目标设备。本人在软件里输入账号、密码、验证码；保留双重认证，不交给助手或上传仓库。
5. 签名成功后找到**新生成的已签名 IPA**，再安装到刚才选定的手机。原始未签名包与新产物不能混淆；签名成功不等于安装完成。
6. 按手机提示完成开发者模式与开发者签名信任。仅有 WDA 图标不能证明自动化通道可用。
7. 运行本套件 Configure.ps1，重新发现实际 bundle ID。若有多个候选，明确选择；不自动删除其他 runner。
8. 运行 Start.ps1，在手机完成 XCTest 确认；在非敏感页面验证原生 XML、点击、滑动、截图和实时画面。

步骤 3—5 参考[官方签名教程](https://www.i4.cn/news_detail_38195.html)，实际菜单以安装版本为准。

## WDA 的额外要求

WDA 含主程序、嵌套 `.xctest` 和 framework，必须具备正确签名、描述文件与开发权限。普通 IPA 能安装，不代表 XCTest 能启动 WDA。不得为了签名成功删除测试插件或运行所需 framework。现有 no-dsym IPA 仅移除调试符号，其余运行文件字节未改。

签名/安装成功但启动超时，应依次区分证书不信任或过期、插件签名、开发者模式、DDI、隧道及手机验证。不要将所有失败都解释为大陆网络问题，也不要循环输入密码、关闭双重认证或关闭杀毒软件。

## 续签与回退

免费个人签名仍约 7 天有效。爱思覆盖续签尚未实测：使用同账号、设备、源 IPA 与一致的 bundle ID，先确认软件允许覆盖再操作，不先卸载可用版本。签完后重新 Configure、Start 并验证。

爱思无法启动 WDA 时，停止该路线，返回原 Sideloadly 工具及相同源 IPA/账号。不要让两个工具同时续签同一 runner。需要删除或更换手机应用时先明确目标及影响。
