# 发布门槛

目标：syotHailin/iphone-windows-bridge。用户已要求加入爱思替代方案并上传；发布时核对仓库登录与权限。爱思路线以未实测候选方案公开，不标为兼容性验收通过。

公开源码前：确认 GitHub 账号、只使用脱敏白名单文件、运行测试与技能验证、检查工作树没有配置/密钥/原始日志。GitHub 上传授权不等于可以上传第三方凭据或私有账号缓存。

公开二进制稳定版前仍须完成：

- 中国大陆干净 Windows 首装、首次签名、首次 DDI 下载/挂载、USB 操作和一次到期续签的现场记录。
- 自建且有对应固定源码的 WDA，限制 MJPEG 监听接口，并进行另一台局域网机器的访问测试。当前 deviceboxhq 第三方产物没有构建来源证明，文件名 13.2.0 与运行时报出 13.1.3 不一致。
- 每个原生二进制的再分发义务核查。Python 包的 LICENSE 与 METADATA 均保留，GPL/LGPL Python 项目对应 sdist 已收集；PyAV 自带 FFmpeg/其他 DLL 的精确构建源码与许可证、go-ios 传递依赖声明仍需复核。不能仅靠“顶层项目是开源”声称整个二进制包已审核完毕。
- 不公开捆绑 Apple、Sideloadly 专有安装器、Apple DDI、个性化签名票据。保留官方下载辅助与失败提示。
- 将 ZIP 与对应 SHA-256 同时放入 Release，不能把 Source code.zip 标成完整安装包；验证匿名下载后的文件哈希。

目前可作为本地测试候选版交付，不标注“大陆全面验证”“永久稳定”“完整安全审计通过”。
